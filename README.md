HTML PRACTICE PROJECT
  This repository contains my practice work with HTML. I explored and implemented a variety of commonly used HTML tags and elements, including:

<!DOCTYPE>, <html>, <head>, <body>

Headings (<h1> to <h6>)

Paragraphs, line breaks, and horizontal lines (<p>, <br>, <hr>)

Text formatting (<b>, <i>, <u>, <strong>, <em>, etc.)

Lists: ordered and unordered (<ol>, <ul>, <li>)

Links and images (<a>, <img>)

Tables (<table>, <tr>, <th>, <td>)

Forms and input elements (<form>, <input>, <textarea>, <select>, etc.)

Semantic tags (<header>, <footer>, <section>, <article>, etc.)

Multimedia tags (<audio>, <video>)

This project helped me understand the structure and purpose of each tag in building web pages.
